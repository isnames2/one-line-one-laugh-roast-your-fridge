A single-line roast of my fridge, written for the make.fun bounty "One Line, One Laugh: Roast Your Fridge".

Bounty: https://make.fun/bounty/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521

The entry is one line, 99 characters:

> My fridge's ice maker produces one cube a day, like it's rationing water for a drought it invented.

`main.py` (pure Python standard library) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, byte-identical on every run.
